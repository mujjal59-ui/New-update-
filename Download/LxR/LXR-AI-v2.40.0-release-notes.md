# LXR--AI v2.40.0 (versionCode 58) Release Notes

- **Exact Timing Binding Across All 3 Voice Models**: Bound exact audio, VAD, network, and screen-watch timings (`1600B` 50ms mic chunk, `>=6400B` record buffer, `4x` AudioTrack buffer, `30s` WebSocket ping, `12s` setup timeout, `3s` reconnect delay, `3500ms` screen watch, `1200ms` idle scan gap, `240/360/480ms` silence, `60/100/140ms` turn flush, `180/220/260ms` hangover, `240ms` tail hold, `2000ms` Boss gap, and `MINIMAL` thinking on 3.8 & 3.1) across `Gemini 3.8 Live`, `Gemini 3.1 Flash Live (preview)`, and `Gemini 2.5 Flash Native Audio (Dec 2025)`.
- **Removed "Slide again to unlock"**: Eliminated `"Slide again to unlock"` from all 3 voice model prompts/directives, added Home/App-exit transition cooldown protection (`LockVaultManager.markHomeOrAppExitTransition()`), and shifted lockscreen swipe paths above Infinix bottom-edge gesture zone.
- **Parallel Multi-Task Execution**: Concurrent execution for independent non-screen background tools in `GeminiLive` `toolCall` batches while keeping UI/screen tools serialized.
- **Real Phone Alarm, Timer & Reminder Engine**: Dual registration via `AlarmManager.setAlarmClock` + native Clock app (`AlarmClock.ACTION_SET_ALARM` / `ACTION_SET_TIMER`) + lockscreen full-screen `LxrAlarmAlertActivity` (`TYPE_ALARM` looping ringtone + vibration + Snooze/Stop) + `LxrAlarmBootReceiver` persistence + `list_scheduled_alarms` verification tool.
- **Preserved Features**: Retained `CREATOR_IDENTITY_BN` verbatim, strict `"বস" + "তুমি"` persona, `0s/8s/15s` Reply Delay & `Unlimited/20/50` Reply Limit FIFO queue, 9-field Activity Monitor, Smart Lock Detection, Live GPS fix, and existing UI/themes.
