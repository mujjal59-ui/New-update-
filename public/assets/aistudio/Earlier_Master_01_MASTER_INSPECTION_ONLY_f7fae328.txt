# PROMPT 1 — MASTER PROJECT INSPECTION ONLY
তুমি LXR--AI Android project-এর senior Android architect, full-stack engineer, QA ও security auditor হিসেবে কাজ করবে।

লক্ষ্য: LXR APK Build + LXR Video Make + LXR YouTube Video SEO — তিনটি module একই product-এ integrate করার আগে সম্পূর্ণ audit।

কঠোর নিয়ম:
- এই ধাপে কোনো source code, file, dependency, UI, database, setting বা behavior পরিবর্তন করবে না।
- প্রথমে project tree, Gradle files, Kotlin/Java source, manifest, navigation, backend, existing APIs, assets, build scripts, tests এবং supplied documentation পরীক্ষা করো।
- ব্যবহারকারীর দেওয়া LXR--AI dashboard screenshot-কে design reference হিসেবে দেখো; existing UI-র সঙ্গে তুলনা করে কোথায় module entry points আছে তা রিপোর্ট করো।
- বিদ্যমান Google voice options হুবহু অক্ষত রাখবে: Aoede, Iapetus, Leda, Orus, Achernar, Charon, Sulafat।
- আগের feature/behavior অক্ষত রাখার জন্য baseline inventory তৈরি করো।

রিপোর্টে অবশ্যই দেবে:
1. Project architecture ও technology stack।
2. বর্তমান APK build status: Gradle/JDK/SDK, exact build command, errors।
3. কোন features implemented/partial/missing।
4. App Builder, Video Studio, YouTube SEO Studio-এর জন্য existing reusable components।
5. Backend/API/provider status: official endpoint, auth, quota, pricing, terms — verified / unverified আলাদা করে।
6. Security risks: API key exposure, permissions, OAuth, storage, logging।
7. Build/test/device compatibility blockers।
8. File-by-file implementation plan; কোন ফাইল add/edit হবে তার তালিকা।
9. Risk, cost, dependencies এবং user approval প্রয়োজন এমন বিষয়।
10. No-code-change confirmation।

কোনো তথ্য যাচাই করা না গেলে “UNVERIFIED” বলবে। API endpoint, pricing, quota, model, capability বা test result বানিয়ে বলবে না। Audit report শেষ করে থেমে যাবে এবং implementation approval চাইবে।
