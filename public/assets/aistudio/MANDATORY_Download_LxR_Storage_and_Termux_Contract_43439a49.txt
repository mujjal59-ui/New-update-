LXR STORAGE & TERMUX OUTPUT CONTRACT — MANDATORY

USER'S REQUIRED PHONE DESTINATION:
Android shared storage folder: /sdcard/Download/LxR/
Termux path after storage permission/setup: ~/storage/downloads/LxR/

All files that LXR creates, downloads, generates, builds or exports for the user must be organized under this folder by default:
- Apps/<ProjectName>/       source project and project files
- APK/<ProjectName>/        APK/AAB outputs and build logs
- Videos/<ProjectName>/     rendered videos and assets
- YouTube_SEO/<ProjectName>/ SEO packages, scripts and research exports
- Images/<ProjectName>/     generated/reference images
- Documents/<ProjectName>/  reports, PDFs and text documents
- Logs/<ProjectName>/       execution/build/render logs
- Backups/<ProjectName>/    user-approved backups

Do not scatter user deliverables in Downloads root or unrelated folders. Keep the original project workspace intact. Ask before overwriting an existing file; use a safe unique filename or versioned backup.

TERMUX SETUP / PATH:
The existing LXR-to-Termux integration must be preserved. If Termux storage has already been granted, use the existing path. Do not blindly rerun setup or change permissions.
Typical Termux path:
  termux-setup-storage   # only if not already granted; user confirmation as needed
  mkdir -p ~/storage/downloads/LxR/{Apps,APK,Videos,YouTube_SEO,Images,Documents,Logs,Backups}

Android shared-storage equivalent:
  /sdcard/Download/LxR/

For a Gradle debug build, use the actual project folder and copy only after successful build:
  gradle assembleDebug
  # verify app/build/outputs/apk/debug/app-debug.apk exists
  mkdir -p ~/storage/downloads/LxR/APK/ProjectName
  cp app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/LxR/APK/ProjectName/

Do not report success unless the command exit code is successful and the artifact exists. Record actual output path and build logs. Never run destructive commands (rm -rf, overwrite, clean) without showing the exact command and obtaining explicit user approval.

IN-APP TERMUX CONSOLE:
Display actual command, cwd, status, stdout/stderr, exit code, timestamps, errors and final artifact path. Stream only if the current bridge supports it; otherwise mark output buffered. Never fake terminal output, progress or ETA.
