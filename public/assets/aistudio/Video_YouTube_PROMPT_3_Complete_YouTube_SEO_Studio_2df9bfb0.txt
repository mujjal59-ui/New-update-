YOUTUBE STUDIO WORKFLOW
A. New project: video upload or existing Video Studio project handoff; YouTube URL metadata import where permitted; manual entry fallback.
B. Brief: topic, niche, target audience, language (Bangla/English/mixed), region, video format (long-form/Shorts), duration, primary keyword and goal.
C. Analyze: topic intent, audience questions, keyword variants, competitor/public result research and factual claims. Cite sources and display last-checked dates.
D. Generate SEO Package:
   - 5–10 title options with keyword intent and concise rationale;
   - recommended title plus editable alternatives;
   - natural, useful description with opening lines, summary, chapters, CTA, links placeholder and disclosure where relevant;
   - primary/secondary keywords and keyword clusters;
   - YouTube tags (comma-separated, copy-ready) and hashtags;
   - chapters/timestamps derived from actual runtime/transcript/scene timings; never invent timestamps;
   - pinned comment idea and community post copy as optional extras;
   - Bengali/English/mixed language variants when requested.
E. Script Studio: hook options, full script, intro, sections, examples, transitions, CTA, ending, target duration, narration-friendly formatting and optional Shorts cutdown. Mark factual claims needing review and attach sources.
F. Thumbnail Studio: generate multiple concepts/briefs and connect to actual image generation/editing API if available; 16:9 standard thumbnail, legible text, focal subject, contrast, safe margins, mobile preview; preserve character identity using supplied reference assets when supported. Never claim a thumbnail image was generated if only a text prompt was produced.
G. Shorts Studio: vertical 9:16 creative brief, short hook, script, title, description, hashtags and optional thumbnail/cover.
H. Optimize & validate: title/description relevance, keyword stuffing warnings, readability, factual claim checks, duplicate tags, policy/copyright reminders and checklist. Any score must be transparent heuristic, not official YouTube ranking score.
I. Preview & export: editable metadata preview, copy individual fields, copy full package, export TXT/JSON, save drafts, version history and restore.
J. Publish/analytics: do not auto-publish. If official YouTube Data API / Analytics API is configured with explicit OAuth consent, provide only authorized supported actions and real metrics. Otherwise provide manual copy/export. No fake views/rank/CTR analytics.

QUALITY / HONESTY
- Never promise 100% SEO, guaranteed ranking, viral reach, views or CTR. SEO tools can improve relevance and packaging; audience interest, retention, competition and platform systems affect results.
- No fabricated keyword search volume, trend score, competitor data, ranking or analytics. Label estimates and explain source/method.
- Research providers must not invent citations. Validate URL and source availability; distinguish source fact from generated suggestion.
- Do not keyword-stuff or generate misleading titles/thumbnails.
- Respect YouTube policies, copyright, privacy, music and image licensing.
- API keys server-side only. Verify current official endpoints, pricing, quotas, terms and rate limits. Free does not mean unlimited. No paid API use without explicit approval.
- Track real provider/model, latency, tokens/cost where returned, quota errors, retries and fallback; avoid duplicate requests.
- If a provider is unavailable, skip it and transparently continue with available sources; never fake a response.
