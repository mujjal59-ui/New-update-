VIDEO CREATION SECTION — AUDIT THESE CAPABILITIES
1. Idea/prompt to storyboard, script, scenes and shot list.
2. Text-to-video and image-to-video provider integration (শুধু বাস্তবে উপলব্ধ API থাকলে)।
3. Character consistency, character/reference assets, scene continuity, expressions, pose/motion, voice/dialogue.
4. Scene editor: timeline, shot order, trim, split, transitions, overlays, captions/subtitles, music/SFX, aspect ratio and resolution.
5. Voice generation and synchronization; preserve the seven existing Google voices.
6. Asset library: uploaded images/videos/audio, generated assets, licensing/source metadata.
7. Render/export: MP4, supported codecs/resolutions/frame rates, progress, retry/resume/cancel if provider supports it.
8. OpenMontage adapter: determine its exact real capabilities. Do not call template/slideshow/pan-zoom output generative text-to-video. Identify which parts are local rendering, stock footage, SVG/rig animation, or actual generative AI.
9. Production dashboard: job queue, stages, logs, provider status, real progress, ETA only when measurable, failure reason and retry.
10. Mobile UX: upload, preview, edit, export, background task recovery and storage limits.

YOUTUBE VIDEO + SEO SECTION — AUDIT THESE CAPABILITIES
1. YouTube URL/video metadata import where permitted; manual project input fallback.
2. Video topic, audience, language, region, niche, target keyword and search-intent analysis.
3. SEO title alternatives with rationale; description; primary/secondary keywords; tags; hashtags.
4. Script generation/refinement: hook, intro, sections, CTA, ending, spoken language and target duration.
5. Chapters/timestamps based on actual video/script duration; never invent timestamps.
6. Thumbnail concept generation and image generation/editing integration; 16:9, mobile legibility, safe margins, text variants, face/character consistency.
7. Shorts packaging: short title, hook, description, hashtags and vertical 9:16 creative brief.
8. Competitor/topic research and factual verification with source citations and publication dates.
9. Pre-publish checklist, metadata preview, copy/export, saved drafts and version history.
10. Analytics integration only through official authorized YouTube/Google APIs and user consent; distinguish actual analytics from estimates.
11. Never promise “100% SEO”, guaranteed ranking, views, CTR or virality.

PROVIDER RESPONSIBILITIES TO VERIFY
- FreeLLMAPI: generate SEO title, description, tags, script and other text outputs, subject to actual configured models/provider quotas.
- OmniRoute: select/route to an appropriate LLM using task type, quality, latency, context size, availability and cost/approved-free-tier constraints. Do not assume it itself is an LLM.
- Perplexity + You.com: research, discover sources, cross-check facts, retrieve citations and freshness. Use official supported APIs only.
- Phind: optional additional research provider ONLY if a current, official, usable API and terms are verified. Otherwise mark unavailable and do not create a fake adapter.
- OpenMontage: video/visual production only for capabilities actually supported by the inspected repository and connected services.
- LXR--AI orchestrator: combine outputs into one coherent SEO Package and one production workflow; deduplicate, resolve conflicts transparently, preserve citations and label unverified claims.

SECURITY / COST / RELIABILITY
- API keys and provider secrets server-side only; never hardcode in Android app, APK, logs or repository.
- Verify endpoints, auth, request/response schemas, rate limits, terms, pricing and free quotas from official sources.
- No paid API/provider calls unless user explicitly approves. Free tiers are not unlimited; do not promise fixed token quota or fabricate balances.
- Track actual provider, model, request ID, token usage/cost when returned, quota errors, fallback and timestamps. Do not invent usage.
- Respect copyright, stock asset licenses, music rights, privacy and YouTube policies.
- Retry with bounded backoff; avoid duplicate billing; idempotency where possible; cache safe research; graceful fallback.
- User can review/edit generated outputs before publishing/export.
