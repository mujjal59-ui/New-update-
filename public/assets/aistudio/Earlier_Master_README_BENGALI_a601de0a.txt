গুরুত্বপূর্ণ:
এই ZIP হলো Google AI Studio/কোডিং এজেন্টের জন্য পূর্ণাঙ্গ পরিকল্পনা, নির্দেশনা, ডিজাইন রেফারেন্স ও যাচাই-চেকলিস্ট। এটি নিজে থেকে APK বা ভিডিও তৈরি করে না এবং আপনার মূল Android source project-কে পরিবর্তন করে না। বাস্তব APK তৈরি করতে আপনার সর্বশেষ Android source ZIP-টিও আলাদাভাবে AI Studio-তে আপলোড করতে হবে।

প্যাকেজে যা আছে:
1) Master inspection prompt — আগে পুরো project, build system, backend, API ও security audit করবে; কোনো কোড পরিবর্তন করবে না।
2) LXR APK & Any-App Builder prompt — নতুন Android app পরিকল্পনা, UI, architecture, code, tests, build ও APK export workflow।
3) Video Creation Studio prompt — script/storyboard/scene/voice/assets/timeline/render workflow।
4) YouTube Video SEO Studio prompt — research, titles, description, tags, chapters, thumbnail brief, Shorts এবং export।
5) Unified orchestration prompt — FreeLLMAPI, OmniRoute, Perplexity, You.com, optional verified Phind, OpenMontage এবং LXR--AI-এর দায়িত্ব।
6) User-provided LXR--AI mobile dashboard screenshot as UI reference.

ব্যবহারের সঠিক ক্রম:
A. Google AI Studio-তে আপনার সর্বশেষ Android source ZIP + এই ZIP আপলোড করুন।
B. প্রথমে 01_Master_Prompts/01_MASTER_INSPECTION_ONLY.txt পাঠান। এটি শুধু পরীক্ষা ও রিপোর্ট করবে; কোড বদলাবে না।
C. রিপোর্ট যাচাই করে অনুমোদন দিলে 02_APK_AND_ANY_APP_BUILDER.txt পাঠান।
D. APK অংশ build/test হওয়ার পর 03_VIDEO_CREATION_STUDIO.txt পাঠান।
E. এরপর 04_YOUTUBE_VIDEO_SEO_STUDIO.txt পাঠান।
F. সব মডিউল আলাদাভাবে যাচাই হলে 05_UNIFIED_LXR_ORCHESTRATION.txt পাঠান।

সীমা ও সতর্কতা:
- “যেকোনো অ্যাপ তৈরি” বলতে AI-সহায়তায় বিভিন্ন ধরনের Android app-এর পরিকল্পনা/কোড তৈরি বোঝায়; সব app স্বয়ংক্রিয়ভাবে build বা install হবে—এমন নিশ্চয়তা নয়। প্রতিটি app-এর requirements, permissions, SDK/API, device compatibility, signing এবং testing লাগবে।
- APK build করতে Android SDK/Gradle/JDK এবং প্রয়োজনীয় dependencies থাকতে হবে। Build environment না থাকলে সুনির্দিষ্ট blocker দেখাতে হবে; ভুয়া success নয়।
- FreeLLMAPI হলো LLM gateway/provider, video generator নয়। OmniRoute হলো task অনুযায়ী LLM routing layer, নিজে model নয়।
- Perplexity ও You.com research/fact-checking-এর জন্য; official API availability, auth, terms, rate limits যাচাই করতে হবে।
- Phind কেবল কার্যকর official API ও অনুমোদিত integration যাচাই হলে optional provider হবে।
- OpenMontage-এর বাস্তব verified capability অনুযায়ী video/visual production হবে। Remotion/FFmpeg/GSAP দিয়ে rendered motion graphics তৈরি করা text-to-video generative AI-এর সমতুল্য নয়।
- প্রকৃত text-to-video বা image-to-video-এর জন্য আলাদা verified provider API প্রয়োজন হতে পারে।
- Paid API call, subscription, cloud render বা credit খরচের আগে ব্যবহারকারীর স্পষ্ট অনুমতি নিতে হবে।
- API key কখনো APK, client-side code, Git repo বা log-এ রাখা যাবে না; backend secret store/environment variables ব্যবহার করতে হবে।
- YouTube analytics/upload-এর জন্য official OAuth consent ও supported YouTube API দরকার। না থাকলে manual export/copy workflow দিতে হবে।
- SEO score কেবল heuristic; ranking, views, virality বা CTR guarantee করা যাবে না।
- বিদ্যমান Google voice options অপরিবর্তিত রাখতে হবে: Aoede, Iapetus, Leda, Orus, Achernar, Charon, Sulafat।
