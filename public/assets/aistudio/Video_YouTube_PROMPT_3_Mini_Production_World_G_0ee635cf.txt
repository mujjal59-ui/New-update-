## G1. One-Line Story to Complete Video

The user should be able to enter a simple one-line story.

The system should:
1. Analyze the story.
2. Generate a complete screenplay.
3. Create scenes and dialogue.
4. Define characters, appearance, clothing and personalities.
5. Maintain character and scene continuity.
6. Allow the user to review and edit the screenplay.
7. Start production after user approval.
