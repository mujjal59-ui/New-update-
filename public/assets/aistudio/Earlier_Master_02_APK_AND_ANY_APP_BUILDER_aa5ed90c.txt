# PROMPT 2 — LXR APK BUILD + ANY-APP DEVELOPMENT STUDIO
আগের approved audit ও user-approved implementation plan অনুসরণ করে LXR--AI-এর “অ্যাপস তৈরি” module implement করো।

উদ্দেশ্য:
ব্যবহারকারী বাংলায় বা ইংরেজিতে app idea/requirements দিলে LXR--AI তা বিশ্লেষণ করে app specification, screen flow, UI design guidance, architecture, source code, tests এবং buildable Android project তৈরি করতে সাহায্য করবে। Calculator, business, education, utility, productivity, media, ecommerce, dashboard ইত্যাদি বিভিন্ন category support করবে; তবে প্রতিটি app-এর বাস্তব requirements ও platform limitations যাচাই করতে হবে।

Core workflow:
1. Requirement intake: app purpose, target users, platform, features, offline/online, language, design, permissions, data, login, backend, monetization।
2. Clarification: অস্পষ্ট/বিরোধপূর্ণ requirements শনাক্ত করে প্রয়োজনীয় প্রশ্ন করবে; অনুমানকে confirmed fact হিসেবে দেখাবে না।
3. Research & validation: official Android/Jetpack/Google documentation, library maintenance, API documentation, licensing, security, compatibility ও current version যাচাই। Research source URL ও checked date সংরক্ষণ।
4. App blueprint: requirements, screen map, user flows, data model, architecture, API contract, permissions, threat model, test plan।
5. UI/UX: supplied LXR--AI dashboard style reference-কে optional design guidance হিসেবে ব্যবহার; প্রতিটি নতুন app-এর আলাদা theme ও user brief মানবে।
6. Code generation: complete project structure, Gradle config, manifest, Kotlin/Java, Compose/XML, resources, backend stubs only when clearly marked। Placeholder code-কে production-ready বলবে না।
7. Build: available environment-এ Gradle build চালাবে; exact command, build variant, APK path, warnings/errors দেখাবে। Build environment অনুপস্থিত হলে blocker ও local build instructions দেবে।
8. QA: unit, integration, UI, permission, accessibility, security, offline/network, API failure, device-size tests।
9. Export: source ZIP, build report, README, setup instructions, APK only when actually built. APK signing keystore/user secrets নিরাপদে handle করবে; user password চাইবে না বা log করবে না।
10. Change control: user approval ছাড়া unrelated existing files/behavior modify করবে না।

Safety/security:
- Malware, spyware, credential theft, covert surveillance, unauthorized access, harmful automation বা platform-policy violating app তৈরি করবে না।
- Permission least-privilege; sensitive data minimization; secure storage; HTTPS; input validation; dependency review।
- API keys/secrets client APK-তে embed করবে না।
- Third-party API, paid service, cloud deployment, domain, SMS, maps, AI credits বা subscription খরচের আগে explicit approval নেবে।
- Copyright/trademark assets বা proprietary code অনুমতি ছাড়া copy করবে না।

Deliverables:
A) App requirement specification
B) Architecture and screen flow
C) Full source project
D) Buildable APK only if successfully built
E) Test report and known limitations
F) Setup/maintenance guide
G) Change log listing every changed file

Existing LXR--AI features, persona, navigation, data, settings, voice options and visual behavior preserve করবে। Build/test failure লুকাবে না।
