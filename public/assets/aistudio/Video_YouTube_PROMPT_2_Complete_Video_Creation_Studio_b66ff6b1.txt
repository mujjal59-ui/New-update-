VIDEO STUDIO WORKFLOW
1. Project creation: idea/prompt, target platform, language, duration, aspect ratio, resolution, audience and style.
2. Pre-production: outline, screenplay/script, scene breakdown, shot list, narration/dialogue, character bible and visual references.
3. Character & visual continuity: reusable character profiles/reference assets, scene-to-scene consistency, expression/pose/wardrobe notes. Use real supported image/animation APIs; if unavailable, label the capability unavailable and offer a clearly labeled manual/editor workflow.
4. Production: connect OpenMontage only after inspecting its actual modules and documented capabilities. Separate:
   - actual generative text-to-video/image-to-video providers;
   - image sequence / slideshow / pan-zoom;
   - SVG/rigged character animation;
   - stock footage assembly;
   - timeline editing and FFmpeg/Remotion rendering.
   Display the correct production method for each job.
5. Scene editor: reorder scenes, trim/split clips, transitions, titles, overlays, captions, audio tracks, volume, preview and aspect-ratio variants, only to the extent supported.
6. Voice Studio: narration/dialogue, voice selection, pronunciation, subtitle/transcript and sync. Preserve all seven existing Google voices and current settings.
7. Asset management: uploads, previews, generated files, metadata, source/license, reuse and deletion controls.
8. Rendering: queue, render preset, supported export format/codec/resolution/frame rate, storage validation, download/share. Background recovery and resumable render only where technically supported.
9. Production Monitor: real stages, job state, provider/model, timestamps, progress from actual job/provider callbacks, logs, errors, retries, cancel/pause/resume support, and ETA only when defensible.
10. Export handoff: store project metadata and generated assets so YouTube Studio can use the final rendered video without re-upload if feasible.
